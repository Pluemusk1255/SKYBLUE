SHINA'S WORLD — starter website

WHAT'S INCLUDED
- index.html: complete responsive personal gallery website
- images/: put your own JPG, PNG or WEBP images here

PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge or Firefox.

ADD YOUR OWN GALLERY IMAGES
1. Copy your image files into the images folder.
2. Open index.html in a text editor (Notepad or VS Code).
3. Find: const works = [
4. For each gallery item, set image to a relative path, for example:
   image:"images/shina-blue.png"
5. Change title, category and description as desired.
   Categories: vroid, mmd, blender, other
6. Save and refresh index.html.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository named shinas-world.
3. Upload index.html and the images folder (upload the files inside it too).
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish. Your site address will look like:
   https://YOUR-USERNAME.github.io/shinas-world/

NOTES
- No paid domain or hosting is required for this setup.
- Keep image filenames simple (letters, numbers, hyphens).
- Only upload images you own or have permission to publish.
- This is a static site; gallery content is edited in index.html rather than through an admin dashboard.
